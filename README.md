# ESP32 - primeras pruebas

Proyecto de pruebas para ESP32 usando PlatformIO.

Estructura del proyecto:
- `src/` código fuente
- `include/` encabezados y documentación
- `lib/` librerías

Instrucciones:
1. Instalar PlatformIO en VSCode.
2. Conectar la placa ESP32.
3. Usar `pio run` para compilar y `pio run --target upload` para subir.
